# 용돈 챌린지 💰

초등 3학년 딸과 부모님이 함께 쓰는 **할 일 · 용돈 정산 앱**입니다.
매일 해야 할 일을 체크하면 100원씩 모이고, **매주 일요일** 부모님이 현금으로 정산해 줍니다.

휴대폰 홈 화면에 설치해 앱처럼 쓸 수 있는 웹앱(PWA)이고, 인터넷이 없어도 기록이 저장됩니다.

## 바로 쓰기

1. 휴대폰 브라우저에서 아래 주소를 엽니다.
   - https://oraholic.github.io/jade/
2. 홈 화면에 추가합니다.
   - **아이폰(Safari)**: 아래 공유 버튼 → **홈 화면에 추가**
   - **안드로이드(Chrome)**: 오른쪽 위 ⋮ → **앱 설치 / 홈 화면에 추가**
3. 아이 화면에서 오늘 할 일을 누르면 `+100원`이 쌓입니다.

## 화면

### 아이 모드 (기본)
- 오늘 해야 할 일만 요일에 맞춰 보여 줍니다.
- 카드를 누르면 동전 애니메이션과 함께 용돈이 쌓이고, 다 끝내면 축하 화면이 나옵니다.
- **벗은 옷·양말 빨래통에 넣기**처럼 *수시로* 하는 일은 누를 때마다 1회씩 쌓이고, `−` 버튼으로 하나씩 취소할 수 있습니다.
- 이번 주에 모은 용돈, 오늘 진행률, 요일별 막대, 연속 달성 일수를 보여 줍니다.
- 다른 요일은 미리 보거나 지난 기록을 볼 수만 있고, 체크는 오늘만 됩니다.

### 부모님 모드 (PIN)
- 오른쪽 위 🔒 버튼 → PIN 입력. **처음 PIN은 `0000`** 입니다. 설정에서 꼭 바꿔 주세요.
- **할 일**: 추가 · 수정 · 삭제, 요일 지정, 금액 변경, *하루 1번 / 수시로 여러 번* 선택, 잠시 숨기기.
- **기록**: 주간 표에서 요일별 체크를 확인하고, 칸을 눌러 고칠 수 있습니다. 수시로 하는 일은 횟수 조절 창이 열립니다.
- **정산**: 이번 주 금액을 확인하고 **이번 주 용돈 정산하기** → 금액·메모를 남기면 정산 내역에 기록되고 아이 화면의 이번 주 금액이 0원부터 다시 시작합니다.
- **설정**: 아이 이름, 체크 소리, PIN 변경, 기기 동기화, 백업/복원, 초기화, 홈 화면 설치 안내.

## 여러 기기에서 함께 쓰기 (선택)

기본은 이 휴대폰에만 저장됩니다. 부모님 폰과 아이 폰이 같은 기록을 보게 하려면 Firebase 무료 데이터베이스를 연결하세요.

1. [Firebase 콘솔](https://console.firebase.google.com)에서 프로젝트를 만듭니다.
2. **빌드 → Realtime Database → 데이터베이스 만들기 → 테스트 모드**를 선택합니다.
3. 화면 위의 주소를 복사합니다. (예: `https://내프로젝트-default-rtdb.firebaseio.com`)
4. **규칙** 탭에 아래를 붙여넣고 게시합니다.

```json
{ "rules": { "families": { "$code": { ".read": true, ".write": true } } } }
```

5. 앱의 **부모님 모드 → 설정 → 가족 기기 동기화**에 주소를 넣고, **자동 생성**으로 가족 코드를 만든 뒤 **동기화 켜기**를 누릅니다.
6. 다른 폰에서도 같은 주소와 가족 코드로 연결하면 몇 초 안에 기록이 맞춰집니다.

> 가족 코드는 12자 이상 무작위로 만들어 주세요. 주소와 코드를 아는 사람은 접근할 수 있으니 가족끼리만 공유하세요.
> 더 강한 보안이 필요하면 Firebase 인증을 추가해야 합니다.

## 데이터

- 체크 기록과 정산 내역은 이 기기의 브라우저 저장소(localStorage)에 저장됩니다.
- 설정에서 JSON 백업을 내려받고 복원할 수 있습니다. 백업 파일에는 동기화 주소·코드가 포함되지 않습니다.
- 100원, 매주 일요일 정산이 기본값이며 부모님 모드에서 금액과 할 일을 바꿀 수 있습니다.
